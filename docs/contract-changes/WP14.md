## 2026-09-24 — parseLaunchParams: random default seed needs an entropy input
- **WP:** WP14
- **Change:** `export function parseLaunchParams(search: string, settings: Settings, randomSeedText?: string): LaunchParams;`
  (additive optional 3rd parameter; used as `seedText` when `seed` is absent and `settings.lastSeed` is empty).
- **Rationale:** `LaunchParams.seedText` (core/debug.ts:12, DESIGN.md 2441 and §7.1 `seed` row) defaults to a random
  `NNNN-NNNN`, but `src/app/urlParams.ts` is a PURE module (§3.3, tests/arch) and may not call `Math.random`.
  WP0 workaround: the stub returns `''` and `App.ts` replaces it with a random seed.
- **Consumers affected:** WP14 only (`app/App.ts`, `tests/app/urlParams.test.ts`).
