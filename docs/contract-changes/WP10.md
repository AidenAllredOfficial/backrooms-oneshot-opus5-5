# Contract change proposals — WP10

## 2026-09-24 — Light-volume texel order and 3D texture axes
- **WP:** WP10
- **Change:** doc-only, `src/core/mesh.ts` `LightVolumeData`: add
  `/** Sample (i along x, k = LV.Y level, j along z) is at index ((j * LV.NY + k) * LV.NX + i) * 4 in a, b and c.
   * Uploaded as Data3DTexture(width = LV.NX, height = LV.NY, depth = LV.NZ): texture u = x, v = level, w = z. */`
- **Rationale:** the contract gives only the length (`LV.NX*LV.NY*LV.NZ`). The producer (WP7 volume.ts), the uploader
  (WP10 `acquire3D(w, h, d)`), the shader (WP9 props uvw) and the CPU sampler (WP11 `camIrradiance`) must agree on
  the index order and on which axis is the texture's height or depth. The WP0 stub streamer uploads with
  (w, h, d) = (LV.NX, LV.NY, LV.NZ).
- **Consumers affected:** WP7 (bake/volume.ts), WP9 (props variant LV lookup), WP10 (ChunkStreamer texture step), WP11 (camIrradiance).
